How the ranking works

Every search runs three data-structure steps on the server:

  1. Linear search over the product catalogue, scored so prefix matches rank first.
  2. Merge sort — stable, O(n log n) — orders those matches by relevance.
  3. MinHeap holds every stocking shop keyed by Haversine distance; the k nearest are extracted in O(n + k log n).

Placing a request uses the project's core structure: a Queue built as a circular array, so joining the line and being served are both O(1).
