What runs on every search

  1. Linear search over the catalogue, scored so prefix matches rank first.
  2. Merge sort — stable, O(n log n) — orders matches by relevance.
  3. Haversine distance from you to every stocking shop.
  4. MinHeap extracts the k nearest in O(n + k log n).

Reserving an item uses the project's core structure: a Queue built as a circular array — joining the line and being served are both O(1).
