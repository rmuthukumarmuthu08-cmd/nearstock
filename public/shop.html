Customer request queue

FIFO — the front of the line is served first. Enqueue and dequeue are both O(1).
Circular array — the queue's backing store
enqueue writes at rear, then rear = (rear+1) % n
dequeue reads at front, then front = (front+1) % n
Nothing shifts, so both stay O(1) — unlike Array.shift(), which is O(n).
◀ Front — waited longest, served next Rear ▶ — most recent request
